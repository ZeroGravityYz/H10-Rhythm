# Contribuer

Merci de décrire clairement le problème, la version Android, le modèle du téléphone et les étapes de reproduction.

Pour les changements du moteur ECG :

- ajouter un test reproductible ;
- distinguer les problèmes de détection QRS, de rythme et de morphologie ;
- ne jamais présenter une sortie automatique comme un diagnostic ;
- ne joindre aucune donnée ECG personnelle sans consentement explicite et anonymisation.

Les propositions doivent compiler avec le SDK Android 35 et le JDK 17, sans ajouter de service distant par défaut.
